TF-IDF Variant Schemes in Information Retrieval

How different weighting functions impact document relevance and ranking

Standard Raw TF-IDF ntc.ntc

Classical Salton model using raw frequency \(tf_{t,d}\) and \(\log_{10}(N / df_t)\). Susceptible to high term repetitions in verbose documents.

w = tf * log10(N / df)
Logarithmic TF-IDF ltc.ltc

SMART Cornell benchmark using \(1 + \log_{10}(tf)\). Sub-linear scaling prevents single repeated words from overwhelming other relevant terms.

w = (1 + log10(tf)) * idf
Augmented TF-IDF atc.atc

Double normalization factoring maximum term frequency \(\max_t(tf)\). Effectively prevents long papers from biasing ranking scores.

w = (0.5 + 0.5 * tf / max_tf) * idf
Binary / Boolean TF-IDF btc.btc

Binary indicator (1 if present, 0 if absent). Evaluates document relevance purely on concept coverage rather than repetition frequency.

w = (1.0 if tf > 0 else 0) * idf
